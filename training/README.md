# training/ - Model Training Scripts

## train_restoration.py

Trains RestoreUNet to remove DCVC compression artifacts.

**Input data:** `data/restoration_pairs/` with two subdirectories:
- `original/` - clean source frames (PNG)
- `degraded/` - DCVC-compressed-and-decompressed frames (PNG)

Generated by `data_prep/prepare_restoration.py`.

**Loss:** L1 diffusion noise-prediction loss only. VGG perceptual loss is configurable
via `--vgg-weight` but defaults to 0. Do not add VGG: it trains the model to
hallucinate plausible texture that does not match the ground truth, degrading all
metrics (PSNR, SSIM, LPIPS, VMAF).

**Checkpoint layout:** each saved checkpoint is a dict with keys `model`, `ema`,
`opt`, `epoch`, `model_cfg`. The `best.pt` symlink points to the epoch with the
lowest validation loss.

```bash
python training/train_restoration.py \
    --data      data/restoration_pairs \
    --config    configs/gpu/restoration.yaml \
    --ckpt-dir  checkpoints/restore_l1 \
    --epochs    200 \
    --batch-size 8 \
    --save-every 10 \
    --sample-every 20
```

Options:
- `--vgg-weight FLOAT` - VGG perceptual loss weight (default: from config, usually 0)
- `--lr FLOAT` - learning rate (default: 3e-4)
- `--ema-decay FLOAT` - EMA decay for model weights (default: 0.995)
- `--resume PATH` - resume from a specific checkpoint file

## train_sr.py

Trains the 2x super-resolution model (Model S).

**Input data:** `data/sr_enhanced_pairs/` with:
- `hr/` - high-resolution frames (1080p)
- `lr/` - bicubic downscaled frames (540p)

Generated by `data_prep/prepare_sr.py` or `data_prep/prepare_sr_enhanced.py`.

**Loss:** L1 pixel + VGG perceptual + LPIPS.

```bash
python training/train_sr.py \
    --data      data/sr_enhanced_pairs \
    --config    configs/gpu/upscaling.yaml \
    --ckpt-dir  checkpoints/sr \
    --epochs    100 \
    --batch-size 4
```

## Monitoring training

Both scripts log to stdout. Key lines to watch:
- `epoch N  loss=X.XXXX  val_loss=X.XXXX` - per-epoch summary
- `[sample] saved sample grid to samples/epochN.png` - visual check of output quality
- `[ckpt] saved checkpoint/restore_l1/epochN.pt` - checkpoint saved

Sample grids show (left to right): degraded input, model output, clean ground truth.
If the model output looks blurrier than the degraded input, something is wrong with
the data pairing (check that original/ and degraded/ filenames match).
